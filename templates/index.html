课程接入参数

真实模式将连接长江雨课堂执行；认证字段仅存内存，不落盘。填入「演示参数」可离线体验全流程。

运行参数（对应原脚本 .env 配置）

获取配置参数

  1. 课堂参数课程页 URL 中提取：
    classroom_id = 12345678sign = your_sign
  2. Cookie 参数F12 → Application → Cookies：
    csrftoken / sessionid / uv_id

uv_id 即「学校 ID」；三个值分别填入左侧对应输入框

工作原理

  • 课程分析遍历章节，识别视频与图文
  • 任务筛选提取未完成的 leaf 节点
  • 视频模拟播放事件序列＋定时心跳
  • 图文打卡阅读停留后确认已读
  • 进度同步实时状态、断点续看
双模式：演示参数＝离线体验；真实参数＝连接长江雨课堂。
